# OpenForge v1.4 External Evidence Closeout

Date: 2026-05-29
Scope: Phase 20 closeout for v1.4 External Evidence Closure.

## Scope

v1.4 did not add new runtime capability. It turned remaining real-world release
uncertainties into a canonical evidence gate registry and current, redacted
artifacts or precise blockers.

Out of scope for this closeout:

- hosted collaboration;
- cloud workers;
- autonomous remote execution;
- Feishu execution authority;
- Codex Web prompt/turn workflow;
- raw evidence storage.

## Readiness Decision

OpenForge is ready for cautious local-first inspection and trial with explicit
external caveats. v1.4 is complete because it made the external gate states
auditable and truthful, not because every external gate passed.

Do not claim broad first-user or release readiness without these caveats:

- live provider smoke still needs disposable credential evidence;
- physical Windows/WSL terminal behavior still needs real-host evidence;
- Feishu callback remains blocked until public HTTPS and developer-console
  verification exist;
- completed first-user feedback is still missing.

## Redaction Review

Allowed fields recorded:

- command names;
- OS/Node/pnpm/tmux/commit summaries;
- gate states;
- artifact paths;
- blocker names;
- rerun and collection paths.

Forbidden content not recorded:

- provider API keys;
- Feishu secrets, verification tokens, event encryption keys, raw signatures,
  or raw callback bodies;
- JWTs, attach tokens, browser auth tokens, private keys, or passwords;
- raw terminal transcripts;
- provider request or response bodies;
- private project data or local databases.

Secret-pattern scan note: verification scans may match documented forbidden
pattern text or environment variable names in this report and the Phase 20
plan. Those matches are field names or scan patterns, not secret values.
