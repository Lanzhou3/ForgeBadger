## Scope

This report is the master v1.1 evidence matrix for Phases 6-7. It records
whether the remaining v1.0 beta caveats are `Pass`, `Caveat`, or `Blocked`
with exact commands, environments, owners, artifacts, and rerun instructions.
These phases do not add runtime capability; they make external evidence
boundaries inspectable before broader readiness claims.

Historical evidence from May 2026 may be cited as `Baseline`, but it is not a
fresh v1.1 `Pass` unless the command or real-host checklist was rerun for this
phase.

## Evidence Rules

- `Pass` requires fresh Phase 6/7 command output, real-host checklist evidence,
  or real Feishu developer-console callback evidence for live callback gates.
- `Caveat` records unavailable external inputs with reason, owner, and rerun
  path.
- `Blocked` records a product contract failure or unavailable prerequisite that
  prevents a meaningful run.
- Evidence must not include raw API keys, JWTs, Feishu app secrets or tokens,
  provider request bodies, provider response bodies, full model outputs,
  terminal transcripts that may contain secrets, or full auth/config file
  contents.
