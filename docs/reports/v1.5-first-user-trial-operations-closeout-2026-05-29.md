# OpenForge v1.5 First-User Trial Operations Closeout

Date: 2026-05-29
Scope: milestone closeout for v1.5 First-User Trial Operations.

## Scope

v1.5 did not add new runtime authority. It turned the remaining first-user
trial problem into an operator-run evidence loop with tokenless diagnostics,
validated intake materials, redacted packet drafting, packet and issue audits,
candidate issue discovery, and external gate drift guards.

Out of scope for this closeout:

- hosted collaboration;
- cloud workers;
- autonomous remote execution;
- Feishu execution authority;
- Codex Web prompt/turn workflow;
- raw evidence storage;
- automatic external gate clearance.

## Closeout Decision

v1.5 is complete as an operations-tooling milestone: the repository now has a
validated path for collecting, auditing, and routing real first-user evidence.

This closeout does not mean first-user evidence exists. The required next
artifact is still at least one completed, redacted first-user feedback packet
or issue-form feedback item that passes the audit path and receives maintainer
triage.

## Operator Loop

Use this order for the next real first-user collection round:

1. Run `pnpm trial:readiness-validate`.
2. Run the trial with `docs/TRIAL-RUNBOOK.md` and `docs/TRIAL-CHECKLIST.md`.
3. Collect feedback through `docs/TRIAL-FEEDBACK.md` or
   `.github/ISSUE_TEMPLATE/openforge-trial-feedback.yml`.
4. Audit Markdown packets with `pnpm trial:feedback-audit -- <packet.md>`.
5. Audit GitHub issue-form packets with
   `pnpm trial:feedback-issue-audit -- --issue=<number>`.
6. Scan non-tracker candidates with `pnpm trial:feedback-issues-audit`.
7. Run `pnpm evidence:gates-validate` before any external gate registry change.
8. Update `docs/EXTERNAL-EVIDENCE-GATES.md` only after a required artifact is
   linked, redacted, reviewed, and shown to satisfy the clearing condition.

## Redaction Review

Allowed fields recorded:

- command names;
- phase and report paths;
- gate states;
- GitHub issue or PR numbers;
- public GitHub URLs;
- blocker names;
- rerun and collection paths.

Forbidden content not recorded:

- provider API keys;
- Feishu secrets, verification tokens, event encryption keys, raw signatures,
  or raw callback bodies;
- JWTs, attach tokens, browser auth tokens, private keys, or passwords;
- raw terminal transcripts;
- provider request or response bodies;
- private project data or local databases.
