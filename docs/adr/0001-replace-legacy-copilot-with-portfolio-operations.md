# Replace Legacy Copilot with Portfolio Operations

Status: accepted

OpenForge replaces the generic, conversation-centred Copilot runtime with a Portfolio Operations Manager: a durable cross-project controller for request intake, evidence-backed project operations, governed Code CLI execution, and channel delivery. The replacement does not use compatibility adapters, dual writes, or legacy Copilot runs, conversations, memories, pending actions, and tool orchestration as a source of facts. `/portfolio` is the complete primary workspace; `/copilot` is its Portfolio-only alias. The pet opens a Portfolio-only floating companion Dialog: submitted text creates a Portfolio Request, and acknowledgement/progress is read only from its persisted safe status, not a legacy model-chat reply. The alias and Dialog use Portfolio i18n, cannot access legacy Copilot API/runtime/data or execution/terminal-write authority, and cannot expose credentials, raw provider/terminal content, signed action material, or cross-tenant data. Gateway legacy logic remains removed. Historical Copilot tables, migrations, and data remain physically retained with no runtime access, pending separately authorized backup/export and disposable restore. Focused browser and integrated acceptance verification remain deferred.
