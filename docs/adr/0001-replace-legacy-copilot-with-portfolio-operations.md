# Replace Legacy Copilot with Portfolio Operations

Status: accepted

OpenForge will replace the generic, conversation-centred Copilot with a Portfolio Operations Manager: a durable cross-project controller for request intake, evidence-backed project operations, governed Code CLI execution, and channel delivery. The replacement will not use compatibility adapters, dual writes, or legacy Copilot runs, conversations, memories, pending actions, and tool orchestration as a source of facts. A Clean Cutover removes the old runtime and UI only after the new system passes acceptance; old data remains outside the new model and is deleted only during a separately confirmed cleanup.
