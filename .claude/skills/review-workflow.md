# 代码审查工作流

## 触发时机

- GATE 1：计划审查
- GATE 2：实现审查
- GATE 3：零信任验收

## 审查清单

### 安全性
- [ ] 硬编码密钥/凭据
- [ ] SQL 注入
- [ ] XSS
- [ ] 认证/授权正确

### 正确性
- [ ] 错误处理完善
- [ ] 边界情况考虑
- [ ] 并发安全

### 代码质量
- [ ] 函数 >50 行
- [ ] 重复代码 >3 处
- [ ] 嵌套 >4 层

### 架构合规
- [ ] 分层清晰
- [ ] 依赖方向正确
- [ ] 无循环依赖

## 输出格式

```markdown
## 审查报告 — GATE [1/2/3]

### 结论：✅ 通过 / ❌ 不通过

### CRITICAL（阻止通过）
- [文件:行号] 问题 → 建议

### 总结
问题总数：X / CRITICAL: X
```
