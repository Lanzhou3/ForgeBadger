# 规划工作流

## 触发时机

**必须在以下情况使用：**
- 新功能开发（>1天工作量）
- 重构（涉及多个文件）
- API 设计变更
- 任何影响超过半天的工作量的任务

**可跳过：**
- 简单修改（<30分钟）
- Bug 修复（根因明确，单文件）

## 规划模板

```markdown
# 执行计划

## 1. 理解需求
- 目标：
- 约束：
- 风险：

## 2. 影响范围
- 修改文件：
- 新增文件：
- 测试流程：

## 3. 执行步骤
1. [ ] [任务] → 验证方式
2. [ ] [任务] → 验证方式

## 4. 风险与缓解
| 风险 | 缓解措施 |

## 5. 回滚
- 如何回滚：
```

## 规则

- 大任务拆小步骤，每步有验证方式
- 识别阻塞风险
- 标注依赖关系
