# 验证工作流

## 核心原则

**禁止虚标完成。** 任何 Agent 声称完成之前，必须提供实际验证证据，禁止基于推断说"应该通过了"。

## 验证策略

### 代码验证
- [ ] 运行测试套件
- [ ] 边界情况测试
- [ ] 错误路径测试

### 构建验证
- [ ] `npm run build` 成功
- [ ] `npm run lint` 通过
- [ ] `npm run typecheck` 通过

### 功能验证
- [ ] 关键路径手动测试
- [ ] API 端点返回预期结果

## 必须包含

每次任务完成必须包含验证方式：
1. 测试用例（输入 → 预期输出）
2. 或构建/lint 验证
3. 或截图对比（UI 变更）
