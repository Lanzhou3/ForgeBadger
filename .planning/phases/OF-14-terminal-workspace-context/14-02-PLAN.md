# Web Workspace Sidecar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the Phase 14 Gateway workspace tree/file context in Web project and session views.

**Architecture:** Add typed Web API helpers for the read-only workspace endpoints, then build one reusable `WorkspaceContextPanel` client component. Project detail and session detail pages both render the component with a `projectId`; the component handles tree loading, file preview, refresh, empty, and error states without mutating Project Manager evidence.

**Tech Stack:** Next.js App Router, React, TypeScript, TanStack Query, shadcn/ui, lucide-react, Vitest, Playwright.
