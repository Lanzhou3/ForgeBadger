# External Evidence Registry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a canonical external evidence gate registry that prevents release caveats from being cleared without real redacted artifacts.

**Architecture:** This is a documentation and planning-state phase only. Add one registry document under `docs/`, link it from the existing trial/support/open-source entry points, and update planning state without changing Gateway or Web runtime behavior.

**Tech Stack:** Markdown, existing `.planning` GSD files, `rg`, `git diff --check`.

---

### Task 1: Canonical Evidence Gate Registry

**Files:**
- Create: `docs/EXTERNAL-EVIDENCE-GATES.md`
- Modify: `.gitignore`

- [ ] **Step 1: Create registry doc**

Create `docs/EXTERNAL-EVIDENCE-GATES.md` with sections:

- purpose and scope;
- gate state definitions (`Pass`, `Caveat`, `Blocked`);
- gate table for `LIVE-PROVIDER`, `WINDOWS-WSL`, `FEISHU-CALLBACK`, and `FIRST-USER-FEEDBACK`;
- required artifact shape for each gate;
- redaction rules;
- closeout rule stating that mocked tests, docs, and empty templates do not clear external gates.

- [ ] **Step 2: Allowlist the registry doc**

Add `!docs/EXTERNAL-EVIDENCE-GATES.md` to `.gitignore` near the other tracked docs.

- [ ] **Step 3: Verify registry coverage**

```bash

```
