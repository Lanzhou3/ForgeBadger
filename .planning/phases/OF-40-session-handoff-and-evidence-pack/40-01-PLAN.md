# Session Handoff And Evidence Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make local AI CLI session outcomes reviewable through bounded handoff/evidence packs without storing raw terminal history in SQLite or weakening external evidence gates.

**Architecture:** Keep handoff generation in the Web session detail surface using bounded task-packet DTOs, session runtime metadata, and human-authored operator notes. The audit blocks obvious secrets, placeholders, and raw terminal dumps before Markdown export. The generated packet is a review artifact only; terminal scrollback remains tmux-backed and external evidence gates remain unchanged until their real artifacts exist.

**Tech Stack:** Next.js, TypeScript, Vitest, existing Gateway task-packet API, Markdown copy/export helpers.
