# Trial Feedback Draft Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development for
> the generator and verification-before-completion before claiming closure.

**Goal:** Add a secret-safe local command that generates a first-user feedback
Markdown draft without collecting or clearing evidence.

---

### Task 1: Define Generator Contract With Tests

**Files:**
- Create: `scripts/create-trial-feedback-draft.test.mjs`

- [x] **Step 1: Write failing tests**

Tests must prove:

- generated draft includes first-user packet sections and bounded local context;
- generated draft explicitly says it is not submitted, not reviewed, and not
  gate-clearing evidence;
- external gates remain caveat/blocker notes, not pass claims;
- token-shaped values are redacted;
- local command collection is bounded and injectable for tests;
- CLI arguments parse output path and URLs while rejecting unknown flags.

- [x] **Step 2: Verify red**

Run:

```bash
node --test scripts/create-trial-feedback-draft.test.mjs
```

Expected red result before implementation:

- `ERR_MODULE_NOT_FOUND` for `scripts/create-trial-feedback-draft.mjs`.

### Task 2: Implement Draft Generator

**Files:**
- Create: `scripts/create-trial-feedback-draft.mjs`
- Modify: `package.json`

- [x] **Step 1: Build draft function**

Generate Markdown with Summary, Dependency Versions, Diagnostics Export,
Reproduction, Triage, Browser Evidence, External Gate Notes, and Bounded
Support Notes sections.

- [x] **Step 2: Collect bounded local context**

Collect first-line command summaries for:

- `git rev-parse --short HEAD`;
- `tmux -V`;
- `claude --version`;
- optional `opencode --version`;
- optional `codex --version`.

No diagnostics export, browser storage, tokens, provider payloads, Feishu
bodies, or terminal transcripts are read.

- [x] **Step 3: Add CLI and package script**

Expose:

```bash
pnpm trial:feedback-draft -- --output /tmp/openforge-trial-feedback.md
```
