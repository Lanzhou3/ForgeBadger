> validator behavior and verification-before-completion before claiming
> closure.

**Goal:** Add a maintainer-run readiness preflight that aggregates trial intake,
issue-route, and external gate registry validation before real first-user
collection starts.

### Task 1: Define Readiness Contract

**Files:**
- Create: `scripts/validate-trial-readiness.test.mjs`

- [x] **Step 1: Write failing tests**

Tests must prove:

- passing intake, issue-route, and gate checks produce `ok: true`;
- the aggregate result is never gate-clearing evidence;
- failed subchecks produce prefixed errors;
- repository options are forwarded to the issue-route check;
- any subcheck claiming gate-clearing evidence fails the aggregate.
