# Trial Feedback Intake Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development for
> the validator and verification-before-completion before claiming closure.

**Goal:** Make the first-user feedback issue form and Markdown template a
machine-verified intake contract.

**Architecture:** Add a small bounded Node.js validator for the known OpenForge
trial feedback intake surfaces. It checks required GitHub form fields, required
dropdown options, required `validations.required: true` flags, Markdown section
coverage, redaction language, and unsafe raw-evidence wording.

**Tech Stack:** Node.js ESM, `node:test`, GitHub Actions.

### Task 2: Implement Bounded Validator

**Files:**
- Create: `scripts/validate-trial-feedback-intake.mjs`

- [x] **Step 1: Validate GitHub issue form**

Check required field IDs, field types, required dropdown options, required
flags for mandatory fields, caveat owner routing language, and safety language.

- [x] **Step 2: Validate Markdown template**

Check packet sections, dependency/version evidence, diagnostics export,
triage routing, browser/Copilot/terminal evidence, and bounded support notes.

- [x] **Step 3: Block unsafe intake wording**

Reject non-negated requests to paste, upload, submit, or attach raw evidence,
or to paste keys/tokens.

- [x] **Step 4: Provide CLI mode**

`node scripts/validate-trial-feedback-intake.mjs` prints JSON and exits nonzero
when the checked-in contract fails.
