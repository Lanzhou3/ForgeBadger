# Source Env Override Preservation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve command-prefix environment variables when source fallback scripts load repository root `.env`.

**Architecture:** Add a small Node runner that parses root `.env`, merges it behind the inherited environment, and spawns the requested command. Wire Gateway/Web source scripts through it, including a shell mode for Web port default expansion.

**Tech Stack:** Node.js ESM, `node:util.parseEnv`, `node:test`, package scripts, GitHub Actions.

### Task 2: Implement Runner And Wire Scripts

**Files:**
- Create: `scripts/run-with-root-env.mjs`
- Modify: `packages/gateway/package.json`
- Modify: `packages/web/package.json`

- [x] **Step 1: Implement env merge**

Use `node:util.parseEnv` to parse root `.env`. Return `{ ...dotenv,
...inherited }` after filtering out inherited `undefined` values.

- [x] **Step 2: Implement command invocation**

Support:

- direct mode: `run-with-root-env <command> [...args]`;
- shell mode: `run-with-root-env --shell <command>`.

- [x] **Step 3: Wire package scripts**

Gateway:

- `dev`: `node ../../scripts/run-with-root-env.mjs tsx watch src/index.ts`
- `start`: `node ../../scripts/run-with-root-env.mjs node dist/src/index.js`

Web:

- `build`: `node ../../scripts/run-with-root-env.mjs next build`
- `dev`: `node ../../scripts/run-with-root-env.mjs --shell 'next dev -H ${OPENFORGE_WEB_HOST:-127.0.0.1} -p ${OPENFORGE_WEB_PORT:-48732}'`
- `start`: `node ../../scripts/run-with-root-env.mjs --shell 'next start -H ${OPENFORGE_WEB_HOST:-127.0.0.1} -p ${OPENFORGE_WEB_PORT:-48732}'`
