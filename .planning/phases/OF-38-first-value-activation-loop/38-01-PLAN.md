# First-Value Activation Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give new users one Dashboard path from runtime readiness to their first local AI CLI session.

**Architecture:** Keep activation as Web-only orchestration over existing Gateway contracts: dashboard summary, dependency discovery, adapter discovery, project list, and session list. The flow links users to existing Settings, Models, Projects, and Project detail session-launch surfaces; it does not add Gateway launch authority or terminal input paths.

**Tech Stack:** Next.js App Router, React Query, TypeScript, Tailwind CSS, lucide-react, Vitest.
