# Phase 13 Plan 02: Board UI And Work Item Controls

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement behavior test-first. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a visual Project Manager board workflow with edit, delete, and bounded batch status controls while preserving the dense table/detail workflow.

**Architecture:** Keep Gateway as the mutation authority through the Phase 13 Plan 01 API helpers. `ProjectManagerPanel` remains the query/mutation coordinator, adds board/table view state, and renders board controls in the existing Project Manager card so route, tab, ledger, and detail behavior stay localized.

**Tech Stack:** Next.js App Router client component, React, TanStack Query, existing shadcn/radix UI primitives, Playwright E2E.
