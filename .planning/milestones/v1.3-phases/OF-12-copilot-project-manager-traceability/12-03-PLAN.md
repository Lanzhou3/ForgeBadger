<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gateway DTO -> Web typed client | Server response data becomes TypeScript DTOs and helper input. |
| Pending action input/result -> Copilot summaries | Stored Gateway payloads are transformed into visible UI summary copy. |
| i18n copy -> rendered UI | Localized strings and user-supplied marker values are combined in React components. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-03-01 | Information Disclosure | `getCopilotPendingActionSummary` and `getCopilotEventResultSummary` | mitigate | Read only allowlisted PM fields; tests assert raw prompt, terminal, provider, diff, stdout/stderr, and raw summary fields are not surfaced. |
| T-12-03-02 | Spoofing | PM action labels | mitigate | Use fixed action type maps and i18n keys for exactly three PM actions; do not trust model-generated labels. |
| T-12-03-03 | Tampering | Web DTO assumptions | mitigate | Typed `ProjectManagerLedgerTrace` mirrors backend D-07 fields only; no arbitrary `details` property is added. |
| T-12-03-04 | Information Disclosure | Failure/result copy | mitigate | Failure summaries use fixed PM failure code/copy and bounded IDs/counts/status only. |
| T-12-03-SC | Tampering | npm/pip/cargo installs | accept | No package installs are planned; Web uses existing Vitest, React, i18n, and TypeScript patterns. |
</threat_model>
