# Project Manager Workspace Evidence References Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users attach file path, terminal snapshot marker, and session id evidence references to Project Manager work items without storing raw file or terminal content.

**Architecture:** Reuse the existing `ProjectManagerEvidenceRef` allowlist and repository redaction path. Add Web-only evidence-reference presets and validation in `ProjectManagerPanel` so users can create bounded reference objects for workspace paths and terminal/session markers. Keep Gateway persistence unchanged except for focused regression coverage proving `sessionId` references and terminal snapshot markers stay bounded.

**Tech Stack:** Next.js App Router, React, TypeScript, TanStack Query, shadcn/ui, Playwright, Node `node:test`.
