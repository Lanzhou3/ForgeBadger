<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/API client to Gateway REST | Authenticated but untrusted route params, query, and bodies enter project-manager handlers. |
| Gateway route to SQLite repository | Repository must enforce tenant/project scoping even if route code changes later. |
| Copilot model/tool input to repository | Model-generated tool input is untrusted and must be validation-bounded; read tools cannot mutate. |
| Feishu public/inbound text to Copilot | Feishu text remains collaboration input only after Phase 2 safety gates; it cannot approve, control terminal, or mutate ledger directly. |
| Gateway to diagnostics export | Diagnostics may be shared for support and must not contain raw ledger/evidence/terminal/Feishu/provider secret data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | `ProjectManagerRepository`, REST routes, Copilot tools, diagnostics | mitigate | Add `user_id` and `project_id` columns, repository-level `WHERE user_id = ?` and `project_id = ?`, route project visibility checks, and owner/foreign-user tests for repository/routes/tools/diagnostics. |
| T-04-02 | Elevation of Privilege | Feishu ingress, Copilot pending actions, route mutations | mitigate | Add no Feishu direct ledger mutation path; preserve existing pending-action approval routes; no terminal input route is touched; run Feishu/Copilot regression commands in final verification. |
| T-04-03 | Information Disclosure | Ledger event details, audit details, Copilot outputs, diagnostics | mitigate | Normalize/redact evidence/details before persistence/output; store references and counts only; diagnostics never serialize raw `details_json`, raw evidence blobs, terminal history, webhook secrets, provider credentials, tokens, signatures, or CLI stderr. |
| T-04-04 | Repudiation | Work item status mutation | mitigate | Repository rejects `done` without evidence refs or manual completion reason and always appends a ledger event plus redacted audit row in the same transaction. |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs are planned; use existing Drizzle SQLite, better-sqlite3, zod, Express, and node:test stack. |
</threat_model>
