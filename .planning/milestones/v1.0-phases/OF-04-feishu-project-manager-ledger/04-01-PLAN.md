<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/Copilot client to Gateway REST | Authenticated user input crosses into project-manager route handlers and must be zod-validated. |
| Copilot tool execution to Gateway repository | Model/tool inputs are untrusted; read tools must stay tenant-scoped and mutation proposals must not bypass pending-action semantics. |
| Feishu ingress to Copilot/Gateway | Feishu text is channel input only, not approval authority, terminal input, or ledger mutation authority. |
| Gateway to diagnostics export | Diagnostic output can leave the process and must expose summaries only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Project-manager routes, repository contract, Copilot read tools | mitigate | Require `user_id` on every table, `project_id` on project rows, project visibility checks, repository-level tenant filters, and cross-tenant tests in 04-02. |
| T-04-02 | Elevation of Privilege | Feishu ingress and Copilot pending actions | mitigate | Document that Feishu text cannot approve pending actions, send terminal input, mutate ledger directly, or bypass Gateway approval; implementation must preserve existing pending-action approval routes. |
| T-04-03 | Information Disclosure | Ledger details, audit rows, Copilot outputs, diagnostics | mitigate | Store bounded evidence references and redacted audit details only; diagnostics must expose counts/status markers and never raw ledger, evidence, terminal, webhook secret, provider credential, token, signature, or CLI stderr data. |
| T-04-04 | Repudiation | Work item status transitions | mitigate | Document that `done` requires evidence references or explicit manual completion reason and always appends a ledger event plus audit row. |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new package installs are planned; implementation uses existing Gateway stack. |
</threat_model>
