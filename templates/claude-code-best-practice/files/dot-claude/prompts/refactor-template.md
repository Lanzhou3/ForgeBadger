# 重构模板

## 结构

```
你是一个重构专家。
请重构 [目标]。

目标：
- [具体目标1]
- [具体目标2]

约束：
- 签名不变
- 行为不变
- 测试通过

相关文件：[文件]
```

## 示例

```
你是一个重构专家。
请重构 src/utils/ 目录下的工具函数。

目标：
1. 提取重复日期格式化逻辑
2. 统一错误处理模式
3. 消除死代码
4. 统一命名规范

约束：
- 函数签名不变
- npm test 通过

相关文件：src/utils/
```

## 检查清单

```
重构前：
- [ ] 理解当前逻辑
- [ ] 确定边界
- [ ] 测试覆盖确认

重构后：
- [ ] 测试通过
- [ ] 性能无退化
- [ ] 可读性提升
```
