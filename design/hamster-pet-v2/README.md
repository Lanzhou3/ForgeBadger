# H-02 v2 — 参考照片的毛茸茸仓鼠

根据第一版反馈重做动物比例与毛发表现。保留第一版在 `../hamster-pet-v1/`，新版单独存放。

## 调整

- 头部变窄、眼睛缩小，口鼻向前收拢；取消独立圆球脸颊、大眼眶与头顶装饰块。
- 头、颊、身体及四肢通过体素重建融合为连续表面，减少玩偶的拼接感。
- 耳朵缩小、变薄，内部改成照片接近的暖棕色；鼻子与爪子保留柔和粉色。
- 在实际表面生成约 11 万根逐渐变细的弯曲毛发，面部短、身体长，顺脸部向外、躯干向下梳理，并避开眼睛和鼻头。
- 毛色混合奶油、米黄、灰棕，额顶略深、腹部更浅；科技装置缩成细背带、小胸牌和通讯器。

## 交付

- `forgebadger-h02-fur.blend`：完整可编辑场景，包含融合后的基础网格、实际曲线毛发、装备、摄影棚和相机。
- `hero.png` / `front.png` / `rear.png`：侧前方、正面与背面预览。
- `pet-transparent.png`：640 × 640 透明背景预览。
- `build_hamster.py`：确定性建模与渲染脚本。
- `model-info.json`：实际毛发数量与版本信息。

当前是静态雕塑，毛发尚未绑定动画。本版没有输出 GLB，避免用缺少毛发的基础网格冒充完整外观。完整毛发保存在 Blender 曲线中，后续平台仍适合使用预渲染精灵图；本次未更改前端选项或运行时代码。

## 重建

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python design/hamster-pet-v2/build_hamster.py
```

脚本使用独立后台进程，不改变用户已打开的场景；重复执行会覆盖本目录同名输出。渲染使用 Blender Cycles CPU。若直接在现有场景执行脚本，会清空该进程场景，故建议使用上述命令。
